## 4 大幕次分段与核心任务

### 1. 幕 1 · 一个比 π 更忙的数字（帧 0 – 825，7 镜）
- 钩子开场：从深色背景上巨大的 π 缓缓登场，引入转账/发烧/咖啡场景，打出 `2.718281828…` 小数长河。
- 提问：「它凭什么无处不在？」，账本出现，年份从 2026 倒带回 1683。

### 2. 幕 2 · 一笔算不清的利息（帧 825 – 1814，9 镜）
- 核心画面：复利表格阶梯生长（年结 2.00 ➔ 半年结 2.25 ➔ 月结 2.613 ➔ 周结 2.693 ➔ 日结 2.715）。
- 时间无限切细：公式 `(1 + 1/n)ⁿ` 拼出，n 奔向无穷大 ∞，柱头触顶收敛。

### 3. 幕 3 · 把时间切到无穷细（帧 1814 – 2993，10 镜）
- 伯努利登场：1683 烛光书桌，二项式展开，证明递增且有界。
- **🚨 核心辟谣镜头（重点！）**：弹出分屏，用鲜红斜线划掉 `2.71828`，明确标注伯努利当年只证明了 `2 < L < 3`，这是人类首次用极限定义数！

### 4. 幕 4 · 三次擦肩而过（帧 2993 – 4216，11 镜）
- 三张卡片翻牌：
  - 卡片 1（1618 纳皮尔）：自然对数表，但没有底数概念；
  - 卡片 2（1668 墨卡托）：双曲线面积命名自然对数，仍未点出底；
  - 卡片 3（1690 莱布尼茨）：致信惠更斯，用字母 `b` 标记。
- 三卡向中心叠合，拉出 65 年时间轴，引出欧拉。
